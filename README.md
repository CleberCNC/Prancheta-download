# Prancheta CNC

Programa de desenho e usinagem para máquinas CNC (CAD/CAM), feito por Cleber Martins da Silva.

**Baixar** (o programa avisa sozinho quando sai uma versão nova):

- Windows: [Prancheta-CNC.exe](https://github.com/CleberCNC/Prancheta-download/releases/download/ultima/Prancheta-CNC.exe)
- macOS (Apple Silicon e Intel, macOS 11 ou mais novo): [Prancheta-CNC-macOS.zip](https://github.com/CleberCNC/Prancheta-download/releases/download/ultima/Prancheta-CNC-macOS.zip). Descompacte e arraste o Prancheta CNC para Aplicativos. Na primeira vez o Mac avisa que não pode verificar o desenvolvedor: abra Ajustes do Sistema > Privacidade e Segurança e clique em "Abrir Mesmo Assim".
- Linux (64 bits): [Prancheta-CNC-Linux.tar.gz](https://github.com/CleberCNC/Prancheta-download/releases/download/ultima/Prancheta-CNC-Linux.tar.gz). Descompacte e rode `./instalar.sh` para pôr o programa no menu.
